# 공용 뼈대 (기능 1번이 만들고, 기능 2~5가 사본으로 받는다)

## 평가 기준 파일 — `평가기준_양식.md`

| 칸 | 값 |
|---|---|
| 상태 | 초안 → 확정 (담당자가 「확정」해야 바뀐다. 도구가 바꾸지 않는다) |
| 충족 기준 개수 | 숫자 하나 (예: 3 = 항목 4개 중 3개 이상) |
| 항목 표 | 번호 · 항목 이름 · 기준 내용 · 비고 |

기능 1(`/서류-정리`)은 상태가 「확정」인 파일만 읽는다.

## 결과표 — `결과표.csv` (양식: `결과표_양식.csv`)

한 줄이 지원자 한 명이다. 항목 이름은 기준 파일에서 가져와 「{이름} 판정」 · 「{이름} 근거」 칸 한 쌍으로 늘어난다.

| 칸 | 값 |
|---|---|
| 지원자 ID · 직무 | 가상 ID, 가상 직무 |
| {항목} 판정 | 충족 / 부분 충족 / 미충족 / 근거 없음 |
| {항목} 근거 | 원문 한 줄. 링크에서 나온 근거는 앞에 「[링크]」 |
| 기준 충족 개수 | n/항목 수 (「충족」만 센다. 부분 충족 · 근거 없음은 세지 않는다) |
| 기준 충족 여부 | 충족 / 미충족 (충족 기준 개수 이상이면 「충족」) |
| 링크 확인 상태 | 없음 / 확인됨 / 링크 확인 못 함 |
| 읽기 실패 여부 | 비어 있음 / 「읽기 실패 (사유)」 |
| 서류 합격/불합격 · 면접 대상 | 항상 비어 있음. 사람이 채운다 |

읽기 실패 지원자는 판정 · 근거 · 충족 개수 · 충족 여부 칸이 비고, 「읽기 실패 여부」에만 표시된다.
파일은 UTF-8(BOM 포함) · 엑셀에서 바로 열린다.
